# Proposal

## Why

鲜果集已有订单、退款、买家、商品和库存业务数据，但店主缺少统一的经营分析，也无法管理店员的分模块操作权限。商城首页的轮播图和公告目前没有运营管理能力，现有审计记录也不足以追溯登录来源及高影响操作。

## What Changes

- 新增经营统计工作台，提供销售额与销量、订单量与状态分布、注册与活跃买家、热销商品及库存排行，支持今日、本周、本月、最近 30 天和自定义日期范围，并按日、周、月查看趋势。
- 销售额按成功支付金额减成功退款金额统计，销售量按已支付商品数量减已退款数量统计；活跃买家为统计区间内登录活跃买家与下单买家的去重并集。
- 新增店员账户和权限管理。店主拥有全部权限且独自管理店员账户和权限；店员按商品、订单、库存、售后、内容、统计等模块授权。退款、商品上架/下架、库存调整等高影响业务操作另设独立权限开关，并由后端强制校验。账户与权限变更仅店主可执行并强制留痕。
- 扩展系统审计日志，提供管理员/店员登录日志和业务操作日志，记录操作人、时间、来源 IP、请求路径、结果及目标摘要；系统日志只读，可筛选、分页和查看详情。店员权限变更及高影响操作均写入审计记录。
- 新增商城轮播图和公告管理，支持图片/正文维护、排序、启停、定时上下线、公告置顶及公开展示；商城首页只读取当前已生效的内容。
- **BREAKING**：后台授权由统一 `ADMIN` 角色升级为店主与店员角色及权限集合。所有管理 API 必须执行服务端模块权限和高影响操作权限校验；仅前端隐藏入口不构成授权。
- 保持单店铺范围，不建设多商户、财务结算、数据仓库、消息推送或系统异常监控/告警平台。

## Capabilities

### New Capabilities

- `business-analytics`: 管理端经营统计查询、时间范围和粒度、指标定义及排行。
- `staff-access-control`: 店主/店员账户生命周期、模块权限、高影响操作独立授权及接口访问控制。
- `admin-audit-log`: 管理员和店员登录及管理操作的只读审计查询与留存。
- `storefront-content`: 轮播图、公告的管理、发布生命周期和商城公开读取。

### Modified Capabilities

无已注册主 spec。上述能力均以新增 spec 定义。

## Impact

- 后端：Spring Boot 管理端 API、Spring Security/JWT 授权、认证登录、订单/退款、商品状态、库存作业、买家与管理员账户、审计、商城公开首页内容；新增 Flyway 迁移并同步 H2 测试 schema。
- 前端：Vue 管理后台导航与路由、统计页面、店员及权限页面、日志页面、轮播图/公告编辑与列表，以及商城首页轮播图和公告展示。
- 验证：统计聚合口径及时区边界、店员越权拒绝、店主全权限、敏感操作独立授权和日志原子性、登录日志隐私、内容定时上下线、分页筛选、数据库迁移及桌面/移动端验收。
