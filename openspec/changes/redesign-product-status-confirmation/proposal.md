# Proposal

## Why

管理员点击商品上架、下架后，确认界面出现内容与表格重叠、关闭图标过大、按钮呈原生样式的问题，用户已要求更换界面。需要提供与现有绿色后台一致、独立于表格布局的确认弹窗，让管理员明确操作对象及影响，并获得可靠的提交反馈。

## What Changes

- 将商品上下架确认改为居中的白色卡片，配半透明遮罩、小尺寸关闭图标、明确的标题、商品摘要及操作影响说明。
- 上架采用绿色主按钮“确认上架”；下架采用暖橙色主按钮“确认下架”，两者均提供“取消”，不再使用含糊的“确认”。
- 支持提交中状态、阻止重复请求、弹窗内错误与版本冲突处理；成功后刷新当前筛选列表并提示结果。
- 修复 Element Plus 弹窗样式依赖的加载方式，核对商品删除、分类停用/删除、编辑页重新读取等现有确认框的基本显示。
- 明确桌面、手机、长商品名和键盘操作的验收标准。
- 本次范围为商品上下架确认界面与相关样式依赖修复；完整页面改版及其他确认框的内容重设计不在范围内。

## Capabilities

### New Capabilities

- `fruit-catalog`：增补管理员商品上下架确认的界面、明确授权、提交反馈及键盘操作要求。主规范清单目前为空，此处沿用既有 `complete-fruit-catalog-and-management` 变更的能力路径，仅新增确认交互需求，不重复其商品业务规则。

### Modified Capabilities

无已同步到主规范的能力需要修改。既有变更中的商品可见性、上架校验、版本和审计要求作为兼容性约束继续沿用。

## Impact

- 前端：`front-end/src/views/AdminProductsView.vue`、商品状态确认组件（拟新增）、`front-end/src/styles.css`，以及现有 MessageBox 使用处的样式入口。
- 依赖：复用现有 Vue 3、Element Plus 和图标包，采用其官方按组件加载完整样式依赖的入口。
- 接口：复用 `PATCH /api/v1/admin/products/{id}/status` 的 `{ status, version }` 契约及现有商品列表接口。
- 后端：现有分类、图片、SKU、版本校验和操作记录足以支撑新界面，无需新增接口、数据库迁移或修改上下架规则。
- 验证：前端类型检查、生产构建、真实页面与失败场景验收，补充本变更的验收记录。
