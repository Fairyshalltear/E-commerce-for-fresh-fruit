# Proposal

## Why

当前买家登录后只有基础账户信息展示，无法自行维护个人资料或收货地址，商城的买家账户流程因此缺少必要的自助管理能力。补齐个人中心可为后续购物与订单流程提供可信的买家资料和可复用的收货地址。

## What Changes

- 新增买家个人中心，提供个人资料、收货地址和账户安全入口。
- 买家可查看并编辑昵称、手机号和头像；用户名保持不可修改。手机号修改不要求短信验证码，但需校验格式和唯一性。
- 支持头像图片本地上传，并限制文件类型和大小。
- 买家可新增、查看、编辑、删除收货地址并设置默认地址；地址含收货人、联系电话、省、市、区县、详细地址及“家/公司”标签，每位买家最多保存 5 个地址，不包含邮政编码。
- 修改密码时要求验证原密码；成功后清除当前登录状态并要求重新登录。
- 地址和个人资料操作仅作用于当前认证买家；新增或设置默认地址时保证每位买家至多有一个默认地址。
- 管理员端用户管理、账户注销、短信验证及第三方对象存储不在本次范围内。

## Capabilities

### New Capabilities

- `buyer-profile`: 买家个人资料、头像、账户安全和收货地址的自助管理。

### Modified Capabilities

无。项目当前没有已注册到 `openspec/specs/` 的主规格；此前完成变更中的 `user-accounts` 规格尚未同步为主规格。本变更将个人中心行为作为独立的买家资料能力定义。

## Impact

- 后端 Spring Boot 买家 API、服务、持久层、Flyway 数据库迁移及本地头像文件存储与访问。
- 前端 Vue 买家路由、个人中心布局、资料/地址/安全视图及 API 调用。
- 买家资料与地址相关的接口测试、前端类型检查和构建验证。
