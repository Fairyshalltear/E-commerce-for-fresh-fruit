# AI 问答使用说明

商城与个人中心右下角“鲜果问答”打开客服。商品详情的咨询按钮携带当前商品；订单和售后入口携带本人对象。手机采用全屏面板，桌面采用右侧浮窗。Enter发送，Shift+Enter换行；中文输入法候选确认不会误发送，Esc关闭，Tab在面板内移动焦点，关闭后焦点返回入口。

访客可咨询商品、水果知识、已发布FAQ、实际售后政策和应季推荐；订单及退款提示登录。访客token仅存当前浏览器sessionStorage、最多24小时，登录/退出/切换账号清除旧消息及上下文。买家可查看本人历史、续聊和删除，记录从最近活动起保留180天。查看旧回答保留当时来源，新的提问重新读取商品及业务事实。

挑选水果面板填写总预算、份数、月份、用途和礼盒条件。价格与库存来自当前可售规格；没有匹配不自动放宽条件。点击卡片“继续咨询”明确选定对象，“查看详情”进入商品或本人订单页。缺失糖度、配送时间等事实会说明未知。订单和退款属于模拟业务记录，不代表真实承运进度或银行到账。

窗口关闭仅隐藏面板，正在回答的流继续；“停止回答”终止当前尝试并保留已显示的安全文本。网络断线/失败显示真实终态，可读取记录或主动重试；重试保存独立尝试而不重复提问。已停止、失败、拦截回答不能评价；完成的回答可选择有帮助/没帮助，修改只保留一个当前反馈。历史删除需要界面确认，删除后不可恢复正文。

接口未配置、关闭、限额或故障时仍可使用FAQ标准问法、明确商品资料、本人订单/退款和条件推荐；无法可靠识别的表达会请你补充信息。回答可使用在线模型，界面提醒不要输入手机号、详细地址或支付凭据。文字拦截只覆盖管理员维护的规则。

操作截图及本地验证见 [验收记录](ai-verification.md)。
