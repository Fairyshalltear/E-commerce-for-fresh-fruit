# AI 知识库与索引

知识类型包括水果资料 FRUIT、商品补充 PRODUCT、常见问题 FAQ、售后政策 POLICY。FAQ 必須有标准问法，可以维护同义问法；答案为已审核正文。政策编辑时应比较 `/knowledge/business-policy` 返回的实际业务限制：已付款未发货可申请退款，签收后7天内可申请退货，不支持换货，当前物流及退款为模拟流程。

保存仅改草稿并递增并发版本，当前有效修订保持不变。发布保存不可变修订，提交数据库索引任务；完整关键词/FAQ 索引可在无向量配置时首次发布，显示 KEYWORD_ONLY。向量代次启用后须新修订向量完整才切换有效指针，失败显示 FAILED 并保留原有效修订。重试使用当前文档版本，不能重新启用已停用文档。

分块按段落和句子，单块最多700个UTF-16字符，长段约80字重叠，并避免分割代理对。任务具有状态、尝试数、租约和脱敏错误，进程重启可回收过期租约；索引不占用长数据库事务。

每次检索只读取启用文档的有效修订，返回最多6块，知识字符预算4000。FAQ标准/同义问法精确匹配优先；关键词使用本地中文二元字词匹配，向量使用兼容代次及余弦阈值，采用排序融合，避免直接相加不同量纲分数。查询向量错误回退 KEYWORD，不将不兼容维度向量参与比较。

商品更新和状态/分类变化触发同步，并在检索时再次校验当前可见性及商品版本。未完成新索引期间，可读取实时商品资料；动态价格和库存不写死在持久商品知识中。实时商品事实优先于人工补充文档，没有提供甜度实测值时只能说明未知。

更换向量模型/维度创建新 profile，对当前有效知识全量构建，并追赶期间新增的有效修订。切换锁定当前文档，确认当前有效块均有新代次向量才原子替换 ACTIVE 指针。构建失败或取消不影响原代次，迟到任务不能恢复停用文档或切换代次。
