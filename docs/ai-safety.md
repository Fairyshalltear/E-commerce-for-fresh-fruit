# AI 问答规则与数据边界

输入规则支持LITERAL、ALL、ANY，输出支持LITERAL；全部按字面匹配，大小写敏感，不运行正则、代码或任意工具。规则最多20个词、每词100字，按优先级降序及ID升序命中第一条。启停/编辑有版本校验；每条请求固定开始时的规则快照。

输入拦截在外部调用前执行，仅保留“输入已拦截”与规则提示。输出保留最长词长度减一的未发送后缀，扫描后才释放安全前缀，完成时再次检查后缀；Unicode代理对不会被切断。命中后停止实际供应商订阅，原始命中内容不发送也不保留到可见历史，已经显示的安全文字保留为BLOCKED。

JWT决定买家身份，访客高熵token服务端仅存哈希；商品ID检查公共可见性，订单/售后在本人范围查询。没有任意SQL、HTTP、退款审批、下单、库存或账户修改工具。实时业务投影排除地址、手机号、收货姓名、支付信息和内部审核备注，自由文本尽力遮盖电话、邮箱、地址、Key和JWT；这不是对所有自由文本的绝对匿名保证。

模型配置只对OWNER开放，使用AES-GCM加密；读取只有hasKey和固定掩码。模型地址必须符合HTTPS、供应商白名单和公网DNS/实际连接地址策略，不携带Key跟随重定向。仅隔离本地验收显式开启回环接口。框架重试最多一次尝试，每轮最多两次生成，日额度持久化、分钟频率有界，四个活动生成及十六个等待位。

规则命中保存规则ID/版本/阶段和固定摘要，不保存原始命中输出。知识、规则、模型、索引切换与后台对话详情查看复用审计，审计不复制正文/凭据。现有管理员审计保留7天；问答正文买家180天、访客24小时，删除清除原始会话及身份关联，匿名统计事实保留且不能还原正文。管理员记录关键词也按脱敏文本检索。
