# AI 模型配置与运行

项目保留 Java17 与 Spring Boot3.5.16，使用 Spring AI1.1.8 BOM、OpenAI模型Starter及RAG模块。在线模型按数据库配置快照构建 ChatClient/ChatModel、EmbeddingModel，不依赖启动时必需 API Key 的默认单例。Spring AI2.x 需要较新的 Boot，不适用于当前版本。

## 无 Key 启动

所有默认 OpenAI 聊天、向量、图像、审核及音频模型自动配置均禁用。无模型配置时应用正常启动，可准备/发布关键词知识库并运行基础咨询。启用在线模式由店主创建草稿、测试能力后激活；不会在启动时自动发付费请求。

## 凭据及部署

`AI_CONFIG_ENCRYPTION_KEY` 必须为32字节随机主密钥的 Base64 文本，可在本机用 `openssl rand -base64 32` 生成。请通过部署环境配置，不能提交到 Git；聊天 Key 和向量 Key 后续在 OWNER 模型页面填写。保存采用 AES-GCM、随机 nonce、主密钥标识与认证附加数据。缺少或不匹配主密钥只影响在线凭据能力，基础模块仍可使用。轮换主密钥前应备份并通过显式本机重加密迁移密文，不能直接替换后期望旧密文仍能读取。

`AI_ALLOWED_HOSTS` 为逗号分隔供应商域名白名单，默认包括 `*.maas.aliyuncs.com,dashscope.aliyuncs.com,api.openai.com,api.deepseek.com`。仅允许 HTTPS，无 URL 用户信息、查询或片段；校验 DNS 目标和实际连接目标，拒绝私网/回环/链路本地/元数据及保留地址，不跟随重定向。`AI_ALLOW_LOCAL_ENDPOINTS` 默认 false，仅本地 mock 验证时显式启用回环 HTTP。`AI_JOBS_ENABLED` 默认 true；确定性测试可关闭后显式运行索引任务。

## 推荐配置

生成推荐 `qwen3.7-plus`，向量推荐 `text-embedding-v4`、1024维。根据百炼实际中国内地工作空间复制 OpenAI 兼容根地址，例如 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`。根地址已包含 `/v1`，代码追加 `/chat/completions` 或 `/embeddings`，请勿填写具体端点。供应商、模型名称及账户地区可能变化，推荐没有替代真实账户的能力验证。

生成与向量可以使用独立地址、模型和凭据，也可显式复制生成 Key 到向量配置。Key 不写浏览器持久存储，读取只显示“已配置”和固定掩码。

每次保存创建新的配置草稿，baseId 指定继承版本。未提供新 Key 保留原密文，显式清除才删除该草稿中的 Key。激活版本供新请求使用；关闭只去除当前激活指针，已有请求继续持有原不可变快照。

提示模板允许 `{question}`、`{history}`、`{knowledge}`、`{products}`、`{policy}` 五个变量。权限、只读业务、依据约束由领域服务额外加入，店主模板不能覆盖这些约束。

## 删除配置

在模型页选择已保存版本，使用“删除此配置”。确认框说明实际处理方式；未被回答或索引引用的配置永久删除，只有历史回答或失败/淘汰索引引用的配置从列表隐藏、保留追溯。删除后清理该版本的未保存编辑、Key输入和能力测试结果，并刷新列表。

当前激活配置须先关闭在线模型或激活其他版本；处理中回答须等待结束或停止。BUILDING/READY 向量代次须先取消构建，ACTIVE 代次须构建并切换到其他配置的新代次；待处理/运行索引任务解除后才能删除。仅关闭在线生成模型不会淘汰 ACTIVE 向量代次。页面显示阻止原因，服务端同时保护直接 API 请求和并发操作。

隐藏版本不能重新读取、测试、继承、激活或构建新索引，历史回答继续显示当时的模型和配置版本。删除与隐藏均记录安全审计。数据库通过新增 V11 升级，不修改 V9/V10 原迁移。

默认参数：温度0.2、输出1200tokens、最多10个已完成问答对；连接10秒、首内容20秒、空闲15秒、整轮90秒。访客3问/分钟、20问/日，买家10问/分钟、100问/日，全站1000次生成调用/日。框架自动重试设为一次尝试，不暗中增加调用。生成能力测试同样预占全站调用额度；向量索引使用独立有界 worker。

## 验证顺序

先测试 chat、stream、intent、embedding，各能力返回独立成功/失败、耗时和安全错误；然后激活配置、构建向量代次并等待当前有效知识向量完整，再显式切换。不同代次不混用维度；向量不可用时检索回落关键词，聊天不可用时回落基础咨询。

真实供应商验收需要本机配置可用的 API Key，默认测试只运行本地 mock，不调用付费服务。验收记录应记录实际模型、工作空间地区、耗时和 usage；原始 Key、JWT、第三方原始错误及私人业务详情不写入文档或日志。
