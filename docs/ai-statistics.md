# AI 问答统计口径

所有区间按Asia/Shanghai自然日 `[from 00:00, to次日00:00)`，最长180天，默认最近7天；趋势逐日补零。记录列表的日期筛选针对会话更新时间，统计针对问题/尝试创建日，二者不能直接比较。

| 指标 | 公式或来源 |
| --- | --- |
| 提问量 | 唯一接受的question fact；重复key及主动重试不增加 |
| 尝试数 / 重试数 | 实际attempt fact / is_retry=1 |
| 回答成功率 | (COMPLETED+DEGRADED)/全部终态，处理中排除 |
| 降级 | DEGRADED终态单独计数，mode说明实际回答方式 |
| 失败 / 停止 / 拦截 | FAILED / CANCELLED / BLOCKED，各尝试仅一终态 |
| 平均耗时 / 首内容时间 | 有真实时间样本的终态尝试均值；没有样本为null |
| 满意度 | 有帮助/(有帮助+没帮助)，只取完成回答的当前反馈 |
| 评价覆盖率 | 评价数/正常或降级完成数 |
| 高频 / 场景 | 确定场景和安全主题；FAQ按文档ID分组，不能展示私人单号 |

接受前的格式、认证和限流拒绝不计提问；输入内容拦截已经接受，计一提问及一拦截尝试。跨午夜完成仍计在尝试创建日；修改反馈回填原创建日。删除/过期移除正文、主体及request/conversation关联，保留匿名结果和当前反馈快照，历史计数不会因删内容漂移。

例：1个问题重复发送后主动重试，提问量1，尝试2，重试1。1条完成、1条停止、1条处理中，终态2，成功率50%。10条完成中1有帮助、1没帮助，满意度50%，评价覆盖20%。无问题计数为0、趋势补零，高频为空；无评价或终态时比例为null，页面显示无样本。

供应商没有返回usage时保留null，不用框架的EmptyUsage零值冒充实际用量。使用隔离事实用例验证跨日、反馈修改、无样本及匿名化结果，详见 [验收记录](ai-verification.md)。
